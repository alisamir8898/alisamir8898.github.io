# Ali Shalaby — Cybersecurity Portfolio

## Files
- `index.html` — portfolio content
- `style.css` — terminal/cybersecurity design
- `script.js` — mobile navigation
- `assets/Ali_Samir_CV.pdf` — CV used by the Download CV button

## Deploy with GitHub Pages
1. Create a repository named `alisamir8898.github.io` on GitHub.
2. Upload all files/folders from this package.
3. In GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. Your site will be available at `https://alisamir8898.github.io/`.

The portfolio content is based on the uploaded CV and uses the projects/links represented there.
